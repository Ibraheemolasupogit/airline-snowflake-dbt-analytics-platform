# Synthetic Airline Source Data

This directory holds the deterministic, synthetic airline dataset generated by
`scripts/generate_airline_data.py`. It is source-layer data only: no dbt
staging, intermediate, core, or mart modelling of it exists yet, and none of
it is loaded into Snowflake.

Full design documentation lives at
`docs/data_models/airline_synthetic_source_data.md`, and the controlled
exception catalogue at
`docs/data_models/airline_synthetic_exception_catalogue.md`.

## Layout

- `reference/` -- airports (AirStats-style fixture), currencies, exchange rates, airlines, aircraft types
- `operations/` -- aircraft, routes, flight schedules, flight instances
- `bookings/` -- passengers, bookings, booking passengers, tickets, ticket segments
- `pricing/` -- products, services, ancillary services sold, fare classes, fare rules, airport fees, taxes, discounts
- `billing/` -- corporate accounts, travel agents, invoices, invoice lines, payment attempts, payments, refunds, adjustments, credit notes, vouchers
- `exception_manifest.csv` -- the 14 deliberately injected data-quality/financial-control exceptions
- `control_totals.json` -- synthetic source-level control totals (not a warehouse reconciliation result)

## Regenerating

```bash
python scripts/generate_airline_data.py
python scripts/generate_control_totals.py
python scripts/validate_source_data.py
```

Regeneration with the default seed produces byte-identical files. All
passengers, bookings, invoices, and payments are synthetic; no real
commercial or personal data is used anywhere in this dataset.
